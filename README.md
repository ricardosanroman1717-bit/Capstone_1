# Capstone 1: EmporiUm Florida Sales Analysis

# 

# Project Overview

# 

# This project analyzes sales data for EmporiUm, a fictional retail company that sells books, technology, art supplies, and other products.

# 

# My assigned sales territory is Florida, which belongs to the South region. I used SQL to analyze sales performance and Excel to visualize the results.

# 

# Tools Used

# 

# \- MySQL Workbench — Writing and running SQL queries

# \- Microsoft Excel — Creating a PivotTable and PivotChart

# \- GitHub — Organizing and submitting my project

# \- Git Bash — Tracking and uploading project changes

# 

# Sales Analysis Findings

# 

# \*\*1. Total Revenue\*\*

# 

# Florida generated $3,930,187.55 in revenue between January 1, 2022, and December 31, 2025.

# 

# \*\*2. Monthly and Yearly Revenue\*\*

# 

# Florida's annual revenue was:

# 

# \- 2022: $598,413.39

# \- 2023: $917,174.67

# \- 2024: $919,533.85

# \- 2025: $1,495,065.64

# 

# 2025 was the strongest sales year.

# 

# \*\*3. Florida vs. South Region\*\*

# 

# The South region generated $7,996,850.12 in total revenue. Florida contributed approximately 49.15% of that amount.

# 

# \*\*4. Product Category Analysis\*\*

# 

# I analyzed monthly transaction counts and average sale amounts across six product categories using SQL JOINs, COUNT, AVG, and GROUP BY.

# 

# \*\*5. Florida Store Rankings\*\*

# 

# Miami generated the highest revenue at $618,846.25, while Naples generated the lowest at $259,602.83.

# 

# Business Recommendation

# 

# I recommend investigating ways to improve sales at the Naples store. The sales team could review customer demand, product selection, and promotional strategies while comparing its performance with Miami.

# 

# More information about store size, expenses, and customer traffic would help determine the best actions.

# 

# Excel Visualization

# 

# I created a PivotChart comparing Florida's monthly sales revenue from 2022 through 2025. The chart helps show changes in revenue over time.
